# Details

- 用户确认定位更接近产品说明书：让用户知道有哪些功能、看懂真实操作，不沿用以安装和排错为主的快速上手结构。
- 任务拆分时仅授权记录；后续用户已授权录制途径探索与隔离验证，见播放器子任务。不据此推进正文重写、正式播放器接入、提交、推送或 Pages 配置变更。
- 子任务是工作分组，不是已批准的网站目录；先确认结构，再推进对应实现。
- 源码盘点已核对界面、ViewModel 和交互测试；这是静态核对，不代表已运行测试或验证演示效果，也不证明全部功能已包含在 v0.4.3 中。编写和录制时记录对应版本。
- 共通约束：保留 zh-CN / zh-TW / en-US；全宽、侧栏贴左；Markdown 原文展示；尽量复用现成 JS/CSS。
- 演示采用用户已选择的 `asciinema-player` 真实操作回放，不重写模拟 TUI，不提供在线操作 Kodex 的后端；参见[已完成的方案探索](../done/2026-09-08-terminal-demo.md)。
- [真实录制流程](../../shared-context/findings/kodex-terminal-recording.md)已验证并获用户认可；工作台、输入/目录导航、设置场景可复用隔离实录。依赖运行中/历史状态的场景仍须准备安全数据，测试渲染导出尚未实作，不能把通路验证当作所有功能片段完成。
- 各内容子任务须交付经确认结构下的三语言内容、必要的真实操作演示、源码依据及行为边界；用浏览器核对文字、录制、语言切换和窄屏表现。
- 安装、认证、MCP、Hooks、上下文来源等已有内容不直接丢弃；其归属与补充范围由结构子任务核对，不凭此前泛化提纲定稿。
- 复用[主题精简任务](../executable/2026-09-08-minimize-docs-theme.md)，避免重复造文件服务或播放器；该任务尚有开发态新增文件发现检查未通过，不能沿用“全部 HMR 已验证”的结论。
